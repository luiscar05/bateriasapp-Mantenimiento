## Epica 2 - Productos e inventario

### HU-003: Registrar Productos
**Como** Propietario
**Quiero** quiero registrar productos (baterías, claxon, kits de luces) con sus datos técnicos, precio base y disponibilidad
**Para** tener un catálogo único y confiable.

**Cristerios de aceptacion:**
- [] Dado el formulario de producto, cuando ingreso categoría, nombre/referencia, precio base y cantidad, entonces el producto queda guardado.

- [] •	Dado un producto de categoría batería, cuando lo registro, entonces puedo capturar amperaje y potencia (datos técnicos).
